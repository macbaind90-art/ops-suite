PWADC Security Operations Suite v2.4.10 Sync Duplicate Guard

Fixes:
- Bulk roster-to-attendance sync no longer adds missing roster employees.
- New roster employees still sync to Attendance when saved individually.
- Existing roster employees can link/update matching Attendance rows.
- Empty duplicate rows created by previous roster sync are quarantined/hidden, not deleted.
- Attendance views now hide archived/sync-duplicate employee rows.
- Added Hide Sync Duplicates button.
- Safe Sync button relabeled to Link Existing Attendance to better reflect behavior.

Data safety:
- No historical attendance codes are deleted by duplicate cleanup.
- Cleanup only hides r-* sync-created rows that have no meaningful attendance history when a matching live row has real history.
- A backup is attempted before cleanup/sync.
