# PWADC Security Operations Suite v3.1.27

## v3.1.27 Uniform Pants Needed Update

This release keeps the prior Roster / Uniform print polish and adds a fast admin-only bulk action for the current pants order.

### v3.1.27 Notes
- Uniform Accountability now includes **Mark All Pants Needed**.
- The bulk action applies to active Pig employees only and excludes ONIN / APS entries.
- The action keeps pants sizes, notes, quantities, and other uniform rows intact.
- The action writes a roster audit entry with the number of employees affected.
- Roster and Uniform printing still go straight to the system print dialog.
- Uniform print selector remains available for scoped printing.

Build artifact naming is aligned to v3.1.27.
