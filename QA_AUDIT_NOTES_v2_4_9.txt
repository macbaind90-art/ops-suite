PWADC Security Operations Suite v2.4.9 Safe Sync + Scroll Fix

Emergency fixes:
1. Roster -> Sync Attendance is now non-destructive.
   - It no longer merges attendance employee records automatically.
   - It no longer deletes duplicate attendance rows during sync.
   - It updates linked employee metadata and adds missing roster employees.
   - It preserves attendance history even when names/shifts do not perfectly match.

2. Automatic history repair is disabled for safety.
   - The old repair/merge logic can be risky when names differ between roster and attendance.
   - It now shows a safety warning instead of modifying history.

3. 90-Day Grid scroll fix.
   - Selecting/editing a 90-Day Grid cell now preserves scroll position.
   - Keyboard cell updates no longer jump the view back to the top.

Recovery note:
- If v2.4.8 already hid/deleted history during sync, use the attendance backup created immediately before Sync Attendance.
- Backup folder: \\pig-fs\Security\Security Operations Suite\Backups\Attendance\
- The backup timestamp should be just before the sync occurred.
