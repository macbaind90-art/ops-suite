PWADC Security Operations Suite v2.5.1 QA Fix

Audit findings from v2.5.0:
- v2.5.0 was packaged too quickly. The audit module CSS block was accidentally injected into generated HTML string builders, including the schedule share/export builder.
- That created invalid JavaScript before runtime, so the suite could fail even before the audit tools were tested.

Fixes in v2.5.1:
- Removed duplicate audit CSS blocks from generated HTML strings.
- Rebuilt scheduleShareHtml() using a template literal so it cannot be broken by raw newlines in string concatenation.
- Kept one audit CSS block in the primary style section only.
- Verified Badge Audit, AMAG Audit, and Access Audit module files are present in app/modules/.
- Verified Home screen and top nav include Badge Audit, AMAG Audit, and Access Audit.
- Verified inline handler references in app/index.html.
- Verified JavaScript syntax for app/index.html and inline scripts inside all three audit modules using node --check.

Limitations:
- This environment does not have dotnet installed, so full C# publish/compile verification still happens in GitHub Actions.
- The audit modules are intentionally isolated in iframes to prevent their spreadsheet/upload logic from colliding with the suite.
