PWADC SECURITY OPERATIONS SUITE v2.4.8 BUILD KIT

This build adds roster-to-attendance sync and an Archive / Old Employees section.

New in v2.4.8:
- Adding a roster employee syncs them into Attendance.
- Editing roster name, rank, shift, RDO, or start date updates Attendance.
- Removing a roster employee now archives them instead of deleting them.
- Archived/old employees are hidden from normal roster views.
- Archive / Old Employees can be opened from Roster and employees can be restored.
- Manual Sync Attendance button added to Roster.
